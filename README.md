# バス価格監視ボット セットアップ手順

プログラミングやGitHubを触ったことがない人向けに、上から順番にやれば
動くように書いています。全部で30〜40分くらいかかります。

## できること

- 京都→東京・東京→京都 の「今日から30日分」の最安値を5分おきにチェック
- 最安値が変わったら「価格変更ログ」チャンネルに自動投稿
- 価格チェックのたび(5分おき)に、両方向の「安い日TOP5」を自動投稿
- 特定の便・特定の日を登録しておくと、その便の価格が変わったときに
  「◯円→◯円」と、これまでの価格推移(日時つき)を通知
- Discordの決まったチャンネルにコマンドを打つと、最大5分以内に反応します
  (スラッシュコマンドではなく `!list` のような文字コマンドです)

## 全体の仕組み(なんとなくでOK)

GitHubには「Actions」という、決まった時間に自動でプログラムを動かしてくれる
無料の仕組みがあります。これが5分おきに起動して、
1. バス比較なびのサイトから価格を取得
2. 前回の価格と比較
3. 変化があればDiscordに通知
4. Discordのコマンドチャンネルを確認して、コマンドがあれば実行
を行い、取得したデータをこのリポジトリの中に保存して終了する…
というのを5分おきに繰り返します。

---

## STEP 1. GitHubアカウントを作る

まだ持っていなければ https://github.com/signup で無料登録してください。

## STEP 2. リポジトリを作ってファイルをアップロードする

1. GitHubにログインした状態で右上の「+」→「New repository」
2. Repository name に `bus-price-bot` など好きな名前を入力
3. 「Public」を選ぶ(Privateだと後述のActions無料枠が少なくなるため推奨)
4. 「Create repository」をクリック
5. 作成された空のリポジトリ画面にある「uploading an existing file」という
   青いリンクをクリック
6. このチャットで渡したファイル一式(フォルダごと)を、そのままブラウザの
   アップロード画面にドラッグ&ドロップしてください
   (フォルダ構造ごとアップロードできます。`.github/workflows/monitor.yml`
   のようなパスがそのまま反映されればOK)
7. 一番下の「Commit changes」をクリック

## STEP 3. Discord Botを作る

1. https://discord.com/developers/applications を開く(Discordにログインした状態で)
2. 「New Application」→ 好きな名前(例: バス価格ボット)を入力して作成
3. 左メニューの「Bot」を開く
4. 「Reset Token」→表示されたトークンをコピーして、どこかに一時的にメモ
   (**これは絶対に他人に見せないでください**。パスワードと同じ扱いです)
5. 同じ「Bot」ページの中にある **MESSAGE CONTENT INTENT** を ON にする
   → 一番下の「Save Changes」を押す
   (これをONにしないと、コマンドの文字が読み取れません)

## STEP 4. Botを自分のDiscordサーバーに招待する

1. 左メニューの「OAuth2」→「URL Generator」を開く
2. 「SCOPES」で `bot` にチェック
3. 下に出てくる「BOT PERMISSIONS」で以下にチェック
   - View Channels
   - Send Messages
   - Read Message History
4. 一番下に生成されたURLをコピーして、ブラウザの新しいタブで開く
5. 追加したいサーバーを選んで「認証」

## STEP 5. Discordにチャンネルを3つ用意する

自分のサーバーに、例えば以下のようなテキストチャンネルを作ってください。

- `#bus-command`  … コマンドを打つ用
- `#bus-price-log`… 最安値が変わった時の通知用
- `#bus-top5`     … 安い日TOP5用

(指定便の通知は `#bus-command` に届きます。別チャンネルにしたい場合は
STEP 7 で `WATCH_NOTIFY_CHANNEL_ID` を設定してください)

### チャンネルIDの確認方法

1. Discordの設定(歯車マーク)→「詳細設定」→「開発者モード」をON
2. 各チャンネルを右クリック →「IDをコピー」
3. 3つ(または4つ)のチャンネルすべてでIDをメモしておく

## STEP 6. GitHubリポジトリの設定変更(書き込み権限)

自動でデータを保存(git commit)できるようにするための設定です。

1. リポジトリ画面の「Settings」タブ
2. 左メニュー「Actions」→「General」
3. 一番下の「Workflow permissions」で
   **「Read and write permissions」を選択** → 「Save」

## STEP 7. GitHub Secrets(秘密情報)を登録する

トークンやチャンネルIDを、コードに直接書かずに安全に登録します。

1. リポジトリの「Settings」タブ →「Secrets and variables」→「Actions」
2. 「New repository secret」を押して、以下を1つずつ登録
   (Name は下記の通り正確に、Value はそれぞれの値を貼り付け)

| Name | Value |
|---|---|
| `DISCORD_BOT_TOKEN` | STEP3でコピーしたBotトークン |
| `COMMAND_CHANNEL_ID` | `#bus-command` のチャンネルID |
| `PRICE_LOG_CHANNEL_ID` | `#bus-price-log` のチャンネルID |
| `TOP5_CHANNEL_ID` | `#bus-top5` のチャンネルID |
| `WATCH_NOTIFY_CHANNEL_ID`(任意) | 指定便通知を別チャンネルにしたい場合のみ設定 |

## STEP 8. 動かしてみる

1. リポジトリの「Actions」タブを開く
2. 左側に「バス価格監視」というワークフローがあるのでクリック
3. 右側の「Run workflow」ボタン→もう一度「Run workflow」で手動実行
4. 1〜2分待って、実行結果が緑のチェックマークになれば成功
   赤い×になった場合は、その実行をクリックしてログを見ると、
   どこでエラーになったか英語で書いてあります(そのままコピーして
   私に見せてもらえれば直せます)
5. 成功していれば、5分以内に自動でまた実行されます
   (`.github/workflows/monitor.yml` の `cron` の設定で5分おきに動きます)

## STEP 9. Discordで使ってみる

`#bus-command` チャンネルに以下を打ってみてください(反応まで最大5分)。

```
!help
```

```
!list 行き 8/20
```

一覧に出てきた便IDを使って監視登録:

```
!watch 行き 8/20 489949
```

## 注意点・知っておいてほしいこと

- **反応は最大5分遅れます。** GitHub Actionsは5分おきにしか起動しないためです。
  「即座に反応する」ようにするには、別途 常時起動のサーバー(Cloudflare Workers等)
  が必要になります。必要であればいつでも追加できるので、後から相談してください。
- **サイトの構造が変わると動かなくなる可能性があります。** bushikaku.net の
  デザインが変わったタイミングで価格が取得できなくなったら、エラーログを
  見せてもらえれば scraper.py を直します。
- **Actionsの実行履歴・コミット履歴がかなり増えます。** 5分おきに動くので
  1日に最大288回コミットされます。動作としては正常です。気になる場合は
  後で頻度を落とすこともできます(例: 10分おき、30分おきなど)。
- **Publicリポジトリを推奨しています。** Privateだと無料で使えるActionsの
  時間(月2,000分)を使い切りやすいためです。Secretsに登録したトークンなどは
  Publicリポジトリでも外部の人からは見えないので安全です。
- 実行間隔を変えたい場合は `.github/workflows/monitor.yml` の
  `cron: "*/5 * * * *"` の部分を変更してください
  (例: 10分おきなら `*/10 * * * *`)。
